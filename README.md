# Sistema de Gestión de Incidentes Help Desk

## Backend API REST

Proyecto desarrollado para la gestión de incidentes técnicos mediante una API REST implementada con Node.js, Express, Sequelize y SQLite.

---

# Tecnologías utilizadas

| Tecnología | Descripción |
|------------|-------------|
| Node.js | Entorno de ejecución del servidor |
| Express | Framework para desarrollo de API REST |
| Sequelize | ORM para conexión y gestión de base de datos |
| SQLite | Base de datos relacional embebida |
| Postman | Herramienta para pruebas de endpoints |
| Git/GitHub | Control de versiones |

---

# Características del sistema

El backend permite administrar tickets de soporte técnico mediante operaciones CRUD:

- Crear nuevos incidentes.
- Consultar tickets registrados.
- Buscar tickets por identificador.
- Actualizar información del incidente.
- Eliminar registros.
